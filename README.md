# Home Automation Control Using IoT (ESP8266 + Blynk) is a smart IoT-based project that allows users to control multiple electrical appliances remotely using a mobile app or web dashboard.

The system is built using the ESP8266 NodeMCU microcontroller and the Blynk IoT platform, enabling real-time communication over Wi-Fi. Users can switch five different loads (lights, fans, sockets, etc.) ON or OFF from anywhere in the world and receive instant status updates.

This project is ideal for home automation beginners, IoT learners, and embedded systems enthusiasts, and it can be easily extended with sensors, voice assistants, or automation rules.
